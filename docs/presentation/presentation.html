Feature 1

Verbose GC File Support

What

Built-in verbose GC analysis

Verbose GC logs are parsed alongside javacores — heap usage, GC pause times and collection frequency are visualised without any external GC tool.

How to use

Include GC logs in your input

  • Add verbose GC log files to your zip, folder or file list
  • The tool auto-detects and processes them alongside javacores
  • No configuration needed — detection is automatic

Output

GC Activity chart in the report

  • Heap usage, nursery and tenured memory over time
  • GC pause durations overlaid as bars
  • Long Stop-the-World pauses automatically flagged in Tips

GC pause spikes (blue bars) overlaid on heap usage — long pauses flagged automatically in Tips

Feature 2

HAR File Support

What

HTTP traffic analysis inside the report

HAR (HTTP Archive) files capture browser/application network traffic. The tool parses them and surfaces slow calls, error codes and payload sizes — no external HAR viewer needed.

How to use

Include HAR files in your input

  • Add *.har files to your zip, folder or file list
  • Capture HAR from a browser DevTools session or proxy tool
  • The tool auto-detects and includes them — no extra steps

Output

HTTP calls table in the report

  • All HTTP calls sorted by duration
  • Slow calls and 5xx errors highlighted
  • Expandable request / response details per call

All HTTP calls sorted by duration — slow calls and 5xx errors highlighted, with expandable request/response details

Feature 3

AI-Based Thread Classification

What

Automatic thread categorisation by a pre-trained model

Every thread snapshot is classified into a meaningful category (e.g. Computing, Wait For Condition, Read From Database) without any manual inspection.

How to use

Nothing extra — runs automatically

  • Classification runs on every javacore analysis automatically
  • No additional files or configuration required

Output

Classification column + Over Time chart

  • Classification column visible in the All Threads table
  • Thread Classification Over Time chart shows workload shifts
  • Permanently blocked threads flagged in Tips

Each thread gets an AI-predicted class (e.g. Java Internal, Wait For Condition) — visible across all snapshots

Feature 3 — continued

Visual categorisation of thread information

What

Thread count per class across all snapshots

A dedicated chart shows how many threads fall into each category at every javacore timestamp — making workload shifts immediately visible.

Possible thread states

10 classification categories

  • Java Internal
  • Wait For Condition
  • Liberty Internal
  • Display Graphics
  • Read From Network
  • Computing
  • Read From Database
  • Save To Disk
  • Read From Disk
  • Wait For Connection

Output

Thread Classification Over Time chart

If Wait For Condition climbs while Computing drops across snapshots → suspect thread starvation or deadlock.

Thread counts per class over time — workload shifts visible at a glance without reading stack traces

Feature 4

Tips Enhancements

What

Richer, actionable Intelligent Tips

The Tips section is the first place to look. Each tip now includes Evidence, a recommended Action, and the Expected Impact — ranked HIGH, MEDIUM or LOW.

How to use

Open the Intelligent Tips section

  • Tips are generated automatically — no extra input needed
  • Click a thread name in a tip to jump to its drill-down
  • Click a javacore filename to open the javacore detail page

Output

New tips added in this release

  • Long GC pause tip — fires when STW pauses exceed thresholds
  • Permanently blocked thread tip — instant deadlock signal
  • System.exit in main thread detection

Tips ranked HIGH / MEDIUM / LOW with Evidence, Action and Expected Impact — thread names are clickable links

Feature 5

Tool Integration via Plugin Architecture

What

External tools can contribute report sections

Javacore Analyser can be integrated with other diagnostic tools — data from tools like Autogather appears as a dedicated section in the report automatically.

How to use

Include supported tool output in your input

  • Add output files from integrated tools to your zip or folder
  • The plugin detects and processes them automatically
  • No additional configuration required on your part

Output

Additional sections in the report

  • Dedicated section per integrated tool
  • Richer analysis without extra manual steps
  • Custom file types (e.g. Liberty server logs) supported

The Liberty System Out example plugin injects a dedicated report section with severity breakdown and top message IDs
